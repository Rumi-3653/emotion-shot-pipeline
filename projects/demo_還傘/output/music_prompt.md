# 音樂總監輸出——還傘

全片 60 秒 / 8 顆鏡頭 / 風格 preset: 莫蘭迪療癒
情緒弧線: 平靜(1) → 溫暖(2) → 溫暖(3) → 失落(4) → 失落(5) → 期待(6) → 喜悅(7) → 釋然(8)

## Suno prompt(直接貼)
```
lo-fi, soft piano, warm pads, slow tempo, major key, around 84 bpm, instrumental, no vocals, cinematic short-film underscore, emotional arc: opens with a calm mood, builds to a joy peak, then falls into silence before a relieved resolution
```

## 結構指示(挑版本時對照)
- 開場(0%~): 錨定「平靜」,低動態進場,別搶戲
- 高潮(約 72% 處,鏡號7「喜悅」): 全曲能量頂點,前一段必須有明顯堆疊,不能平地起高樓
- 留白(約 85% 處,鏡號8): 高潮後抽掉配器,只留一件樂器或環境聲——這口氣是整支片的呼吸
- 收尾(85%~): 落在「釋然」,向上收,尾音亮

## 混音備註
- 有旁白/台詞的段落走 sidechain ducking,音樂 -8dB 左右自動讓位
- 挑版本標準: 開場收斂、高潮有堆疊、收尾有留白的優先;全程同動態的直接淘汰
